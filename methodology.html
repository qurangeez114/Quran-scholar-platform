Methodology & Transparency

Overview

Quran Hikma is a research tool for identifying and analyzing divergent narrations in hadith literature. This page explains our methodology, data sources, and known limitations.

Analysis Methodology

Selection Criteria: Which Narrations Are Compared?

We identify narrations reporting the same event across different hadith collections and hadith scholars. A comparison is created when:

  1. Two or more narrations describe the same historical event
  2. The narrations come from different collections (e.g., Bukhari vs. Muslim)
  3. There is a substantive divergence in the report (not just stylistic variation)
⚠ Limitation: Selection criteria are not fully formalized. This means our comparison set may not be exhaustive (we may have missed some valid comparisons).

Severity Scoring: What Makes a Divergence "High-Severity"?

Each comparison point is assigned a severity score (1-5) based on how significant the divergence is:

Minor
1
Detail variants, wording differences
Low
2
Modest descriptive divergence
Moderate
3
Meaningful factual difference
High
4
Significant contradiction
Critical
5
Core facts contradict
⚠ Limitation: Severity scoring lacks a published rubric. This introduces subjectivity — different scholars might score the same point differently.

Known Issues

  • Duplicate Entries: Some hadith numbers appear multiple times in source collections with different chains and/or grades. We flag these but do not always resolve which is authoritative.
  • Missing Narrations: 2 narrations (Musnad Ahmad 40, Tafsir Ibn Kathir) could not be sourced and remain in the database with NULL text.
  • Link Verification Incomplete: 76 links remain unverified. While we spot-checked 3 (all correct), a systematic re-verification is needed to ensure URL accuracy.
  • Terminology Ambiguity: "Contradiction" is used loosely. Some entries represent logical contradictions (A vs. ¬A); others represent narrative variants (both could be authentic transmission variants).

What Quran Hikma Does (and Doesn't Do)

✓ What It Does

  • Surfaces narrations of the same event that diverge significantly
  • Preserves original Arabic text (no translation bias)
  • Provides links to primary sources for verification
  • Flags high-severity divergences for scholarly attention
  • Creates an audit trail of analysis decisions

✗ What It Doesn't Do

  • Resolve contradictions: We flag divergences but don't determine which narration is "correct"
  • Provide methodological guidance: We don't explain how classical hadith scholars (e.g., Ibn Hajar) reconciled these narrations
  • Grade narrations: We display collection-level grades but don't conduct independent grading
  • Cite classical scholarship: Our analyses lack references to existing tafsir and hadith works
  • Represent institutional consensus: This is a research tool, not an official Islamic authority

How to Use Quran Hikma

  1. Explore comparisons: Browse the comparison list to find events of interest
  2. Read the narrations: Review the full Arabic texts side-by-side
  3. Examine the analysis: Read our severity assessment and note the divergence
  4. Verify against sources: Click external links to check against sunnah.com (or consult printed editions)
  5. Consult classical scholarship: Reference works like Fath al-Bari (Ibn Hajar's commentary on Bukhari) for how classical scholars reconciled divergences
  6. Form your own judgment: Bring these sources to Islamic scholars for discussion and interpretation

Future Improvements (Roadmap)

  • Complete link verification: Spot-check all 86 links against sunnah.com (or printed editions)
  • Formalize selection criteria: Publish clear rules for when narrations are compared
  • Publish severity rubric: Document the scoring methodology with examples
  • Add scholarly references: Cite classical tafsir/hadith works in analysis sections
  • Implement peer review: Invite Islamic scholars to review and critique analyses
  • Version control: Allow users to see when/how analysis has changed
  • User comments: Enable readers to leave feedback and corrections
