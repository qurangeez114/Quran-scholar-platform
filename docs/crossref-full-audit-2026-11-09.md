## Bugs found and repair branch

1. The original `loadCrossReferences` fetched direct rows **only** inside a fallback that itself required entries in the older thematic table. Direct links were hidden for many verses.
2. `toggleVerse` rendered cross-reference HTML separately, then asynchronously invoked `loadCrossReferences`. The second renderer could overwrite the first.
3. Per-verse count badges read only v2 thematic data, ignoring available direct references.
4. The research lookup in `index.html` filtered `cross_references` using non-existent `sura_id`/`aya_number` and selected non-existent reference fields.
5. The Python API in `main.py` likewise filtered using non-existent `surah_number` and `ayah_number` columns.
6. PostgREST's default response-size cap silently dropped thematic records for seven verses.

Branch `fix/crossrefs-global-display-audit-20261109` makes direct and thematic fetches independent, merges and deduplicates links for display, removes the competing renderer, repairs the incorrect filters, paginates oversized thematic sets, and identifies broad theme associations as such rather than claiming each pair was individually verified.

## Scholarly relevance — follow-up review required

The 11,465 distinct direct-link identities need content-level evaluation against the source and destination verse, the neighboring verses where context matters, and appropriate tafsir/linguistic evidence. A valid verse number alone is insufficient. The v2 table was generated by connecting every member of a large theme to every other member, which produces **very broad associations**; these should not be promoted to verified direct parallels.

Prioritize:
- The **168 uncovered verses** for candidate discovery, without manufacturing links where no evidence is established.
- Surah 37:101–113, especially the sacrifice account; few direct rows are currently present.
- Possible weak pairings such as **37:104 → 21:90** (Abraham being called vs Zechariah's prayer answered) and **37:109 → 19:57** (peace on Abraham vs raising Idris to high station). These are **review flags**, not deletion instructions.
- Exact duplicate direct rows, heavily concentrated in a few source verses, for provenance examination before any data deduplication.
- High-volume all-pairs thematic categories such as resurrection, divine justice, and punishment, which require more selective ranking.

### Review criteria (for every direct pair)

1. Verify both exact Qur'anic verse texts and their surrounding context.
2. Classify the relationship: close lexical parallel, same narrative episode, conceptual echo, legitimate contrast, broad theme only, or unsupported.
3. Record a short specific explanation; add primary-text and scholarly citations where interpretive.
4. Keep external **Sources** (earlier scriptures/historical writings) separate from internal Qur'anic Cross-References.
5. Mark uncertain pairs for human editorial review. Do not infer direct dependence from similar wording.
6. Promote only source-checked relationships. Do not automatically seed a full clique or recreate removed fabricated links.

## Reproducible read-only checks

```sql
SELECT count(*) AS direct_rows FROM public.cross_references;
SELECT count(*) AS ayas FROM public.ayas;
SELECT count(*) AS thematic_rows FROM public.thematic_cross_references_v2;

SELECT count(*) AS distinct_links, sum(n - 1) AS surplus_duplicate_rows
FROM (
  SELECT source_surah, source_ayah, ref_surah, ref_ayah_start, ref_ayah_end, count(*) AS n
  FROM public.cross_references GROUP BY 1,2,3,4,5
) x;

SELECT
  count(*) FILTER (WHERE s.id IS NULL) AS missing_sources,
  count(*) FILTER (WHERE t.id IS NULL) AS missing_targets,
  count(*) FILTER (WHERE te.id IS NULL AND c.ref_ayah_end IS NOT NULL) AS missing_range_ends,
  count(*) FILTER (WHERE c.ref_ayah_end < c.ref_ayah_start) AS reversed_ranges,
  count(*) FILTER (WHERE c.source_surah = c.ref_surah AND c.source_ayah = c.ref_ayah_start) AS self_links
FROM public.cross_references c
LEFT JOIN public.ayas s ON s.sura_id=c.source_surah AND s.aya_number=c.source_ayah
LEFT JOIN public.ayas t ON t.sura_id=c.ref_surah AND t.aya_number=c.ref_ayah_start
LEFT JOIN public.ayas te ON te.sura_id=c.ref_surah AND te.aya_number=c.ref_ayah_end;

WITH d AS (SELECT DISTINCT source_surah s, source_ayah a FROM public.cross_references),
v AS (SELECT DISTINCT sura s, aya a FROM public.thematic_cross_references_v2),
u AS (SELECT * FROM d UNION SELECT * FROM v)
SELECT count(*) AS uncovered
FROM public.ayas a
WHERE NOT EXISTS (SELECT 1 FROM u WHERE u.s=a.sura_id AND u.a=a.aya_number);

SELECT source_surah,source_ayah,ref_surah,ref_ayah_start,ref_ayah_end
FROM public.cross_references
WHERE source_surah=37 AND source_ayah BETWEEN 101 AND 113
ORDER BY source_ayah,ref_surah,ref_ayah_start;
```
